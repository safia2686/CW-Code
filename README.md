
Dataset Information:
The train.csv file has not been included in the GitHub repository as its file size exceeds GItHubs upload limit.
To reproduce the implementation and run the code the dataset must be downloaded separately and then placeed in the project directory.

Dataset download link:
https://www.kaggle.com/competitions/store-sales-time-series-forecasting/data?select=train.csv

The implementation requires the dataset file name and structure to be maintained to ensure the code runs correctly. 

Instructions:
1. Download the dataset using the link.
2. Extract the downloaded files if required.
3. Locate and place the train.csv in the same folder as the main python implementation file.
4. Run the Python script using an IDE such as PyCharm.

Reproducibility:
The complete implementation code is provided within the repository. Even though the dataset is stored separately due to file size restrictions. The marker can reproduce the analysis by downloading the dataset and following the instructions.
